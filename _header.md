# terraform-azurerm-avm-res-botservice-botservice

This Terraform module manages Azure Bot Service. Bot Service resources, channels, and connections use regional locations only for `centralindia`, `westeurope`, and `westus`; other supplied regions map to `global`. Telemetry continues to use the supplied `location`, so set `enable_telemetry = false` when setting `location = "global"` directly. Explicit channel and connection locations are preserved. Private endpoints continue to use their explicit location or the supplied location; provide a regional private endpoint location when using `global`.
